# STUDIO IOS Lexicon

Approved vocabulary, banned words, and the UK-spelling reference. Use this when writing or de-AI-ing copy.

---

## The Studio IOS vocabulary (words that carry the voice)

These are the terms the studio actually uses. They're specific to the discipline and signal that a peer wrote the copy, not a generator.

**Craft & system:**
graphic language · graphic anchor · lockup · badge · wordmark · colourway · silhouette · seasonal direction · style-guide architecture · retail-grade · single source of truth · buyable identity · design system · trend intelligence · category direction · brief · mandate · programme

**Argument & mechanics:**
reads at [distance] · survives [process] · anchors the collection · locks [n] months ahead · carries across [n] collections · sits inside · resolves to · built around · directs · sequences · scales down to a single colour · holds at small size

**Commercial framing:**
sell-through · YoY uplift · preorder · buying cycle · collection window · range coherence · price up · compound the advantage · licensee · category expansion

Use these because they're *true and precise*, not as decoration. A term from this list still has to be earning its place in the sentence.

## Banned words and phrases

These get copy rejected. Each is banned because it substitutes intensity or filler for a specific. When you catch one, replace it with the concrete reason it's true.

**Hype adjectives:**
stunning · striking · dynamic · vibrant · bold (as a standalone claim) · cutting-edge · game-changing · next-level · elevated / elevate · premium (unearned) · bespoke (unearned) · iconic · timeless · unique (when unproven) · powerful · compelling · beautiful · gorgeous · sleek

**AI-tell verbs & nouns:**
delve · leverage · utilise (use "use") · showcase · underscore · boast/boasts · foster · unlock (figurative overuse) · harness · empower · testament · tapestry · symphony · realm · landscape (abstract) · journey (figurative) · ecosystem (figurative) · interplay · synergy · intricacies

**Filler & throat-clearing:**
"In today's fast-paced world" · "In the world of…" · "When it comes to…" · "It's worth noting that" · "At its core" · "Nestled in" · "In the heart of" · "stands as a testament to" · "serves as" · "plays a pivotal/crucial role" · "we're excited to" · "we're thrilled to" · "take it to the next level" · "the perfect blend of"

**Promotional constructions:**
"not just X, but Y" (negative parallelism) · "from X to Y" false ranges · rule-of-three padding · "whether you're… or…" · rhetorical opening questions ("What if…?", "Ever wondered…?")

## Punctuation & formatting house rules

- **Spaced en/em dash ( — )** is the Studio IOS connective for attaching a specific to a claim. On-brand, but ≤ ~1 per paragraph. Never two in one sentence.
- **Slash lists** for placement specs on product/feature lines: `RIGHT-CHEST LOGO / WOVEN HEM BADGE / ACCENT MARK`. Space-slash-space.
- **No exclamation marks.** Anywhere.
- **No emoji.** Anywhere.
- **No Oxford-comma dogma** — Studio IOS copy runs both with and without; be consistent within a single deck.
- **Numbers:** use digits for data (17%, 3 anchors, 9 months). Spell out only where a number opens a sentence.
- **No mechanical boldface** inside body copy. Emphasis comes from the sentence, not from bolding a phrase.

## UK spelling — quick reference

Studio IOS is a Bristol studio. Copy is British English, without exception.

| Use (UK) | Not (US) |
|---|---|
| colour, colourway | color |
| organisation, organise | organization |
| programme (initiative) | program |
| specialise, specialised | specialize |
| centre | center |
| catalogue | catalog |
| favour, favourite | favor |
| recognise | recognize |
| optimise, optimised | optimize |
| licence (noun) / license (verb) | license (both) |
| practise (verb) / practice (noun) | practice (both) |
| grey | gray |
| metre (unit) | meter |
| analogue | analog |
| -ise endings generally | -ize |

When in doubt, default to the `-ise` / `-our` / `-re` forms.
